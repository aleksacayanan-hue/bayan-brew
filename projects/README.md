# Bayan Brew — Sales Performance Dashboard

Portfolio report. The full write-up is in the repository [README](../README.md).

Open `BayanBrew.pbip` in Power BI Desktop. If the visuals are empty, choose **Home → Refresh**.

**Question:** Which stores and products contribute most to revenue, and how do weekends compare with weekdays?

**Data:** Synthetic POS transactions, 1 January 2025 through 30 September 2025. Fictional brand. Not real company data.

Built in Power BI Desktop with Power Query, DAX, and AI-assisted development.
